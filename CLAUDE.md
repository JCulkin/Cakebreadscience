- `claude/notes-shared.md` — read by every website chat (written only by the main chat)
- your own area doc: `claude/notes-main.md`, `notes-questing.md`, `notes-lessons.md`,
  `notes-worksheets.md`, `notes-interactives.md` or `notes-elevenstudents.md`

Read both before working here. Write only to your own area doc (`project_read` it immediately before
`project_write`). `claude/website-workflow.md` is a frozen archive: never write to it.
Do not write notes, guides or READMEs in this repo — except `AGENTS.md` and `.agents/rules/*.md` (user, 25 Nov 2026):
the repo copy of our rules for Google Antigravity and other agents. Only the main chat edits them; other chats put
rule changes under "For main" in their doc.
**Antigravity also pushes to `staging`.** Before regenerating a file from a builder in your workspace, check
`git log -- <file>` for edits made since your last build, and keep them.
Never commit past-paper questions, mark schemes or their images: this repo is public (see notes-shared).
The exam question bank tool (notes-exams.md) is local-only and never works in this repo.
