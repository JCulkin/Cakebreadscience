How it works
Protons = atomic number (never changes).
Electrons = protons − charge.
e.g. Ca2+: 20 protons, 20 − 2 = 18 electrons.
e.g. S2−: 16 protons, 16 + 2 = 18 electrons.

8. Graphite vs diamond
In graphite each carbon atom forms only 3 covalent bonds, so 1 outer electron per carbon is delocalised (free to move) between the layers and can carry charge. In diamond each carbon uses all 4 outer electrons in covalent bonds, so there are no free electrons.
Graphite has delocalised electrons that can move; diamond has none.
Simple molecular substances have low melting points because only the weak forces between molecules break, not the covalent bonds. Giant structures need many strong bonds broken.
