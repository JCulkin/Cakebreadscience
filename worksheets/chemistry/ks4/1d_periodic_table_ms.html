D2. Carbon
Graphite is an unusual non-metal that conducts.
Its oxide (carbon dioxide) is acidic: pH 5.
D3. More reliable test
Graphite shows that conductivity alone can mislead.
The acid–base character of the oxide.
D4. Testing an oxide
Burn the element in oxygen, add the oxide to water, add universal indicator (or use a pH probe): pH below 7 = acidic (non-metal); above 7 = basic (metal).
D5. Bases react with
They neutralise each other to form a salt and water.
Acids
Examiner link: metals form basic oxides (often alkaline in water, pH > 7); non-metals form acidic oxides (pH < 7). Graphite conducts electricity, so conductivity alone can mislead — oxide pH is more conclusive.

E  True or false?

statementanswer
1. Elements in the same period have the same number of outer electrons.False: same number of shells (same group = same outer electrons).
2. The group number of a main group element equals its number of outer electrons.True (Group 0 has full outer shells: 2 for helium, 8 for the rest).
3. Metals are found on the right of the Periodic Table.False: metals are on the left and in the middle.
4. Elements are arranged in order of mass number.False: in order of atomic number (number of protons).
5. Most elements are metals.True.
6. Helium is in Group 0 even though it has only 2 outer electrons.True: its outer shell (the first shell) is full.

G1. Unreactive
They do not need to gain, lose or share electrons, so they are stable.
