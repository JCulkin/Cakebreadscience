Reminder
Elements are arranged in order of atomic number. A column is a group; a row is a period. Electrons fill shells in order: 2 in the first shell, then 8, then 8 (for the first 20 elements). Sodium is 2.8.1.
group number = number of outer electrons  ·  period number = number of shells
