Reminder: the wave equation
v = f × λLEARN THIS ONE
frequency = the number of waves passing a point each second (Hz)
v = wave speed (m/s)  ·  f = frequency (Hz)  ·  λ = wavelength (m)
Every calculation: ① write the equation → ② rearrange → ③ substitute → ④ calculate → ⑤ give the unit
