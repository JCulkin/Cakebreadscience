Which list is in order from smallest to largest?

  1. Cell, organelle, tissue, organ
  2. Organelle, cell, tissue, organ
  3. Tissue, cell, organ, organism
  4. Organ, tissue, cell, organelle

What is a tissue?

  1. A group of organs working together
  2. A structure inside a cell
  3. A group of similar cells working together
  4. A whole living thing

Which of these is an organ?

  1. Muscle
  2. Heart
  3. Nucleus
  4. Red blood cell

Which of these is an organ system?

  1. Leaf
  2. Digestive system
  3. Skin
  4. Mitochondrion

Which of these is a plant organ?

  1. Chloroplast
  2. Leaf
  3. Cell wall
  4. Muscle

Explain the difference between a tissue and an organ. Give an example of each.

  • Tissue: a group of similar cells working together (to do a specific function)
  • Example of a tissue, e.g. muscle
  • Organ: a group of (different) tissues working together (to do a specific function)
  • Example of an organ, e.g. heart / brain / leaf
