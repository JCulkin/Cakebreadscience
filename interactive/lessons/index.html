How drafts, reviews and checked versions work
  1. Draft Claude builds the lesson as a draft. Drafts can change at any time.
  2. Open the draft and press ✎ Review (bottom left). Click any paragraph, diagram, question or projector slide and type what should change. Notes save in your browser.
  3. Press Copy all notes and paste them into a chat with Claude. Claude updates the draft, and you review again.
  4. When you're happy, tell Claude "approve 1f". The draft is frozen as a Checked · date version with its own permanent link. The topic's main link always opens the newest checked version.
  5. Later changes start a new draft. Older checked versions stay available.
