2. Where items come from

  • Starter outfit — deliberately sad (paper hat, school jumper, grey joggers, odd socks, empty crisp packet, slightly bent ruler).
  • Mission drop — every finished mission of 10 rolls one Common/Uncommon item. Same odds for everyone, so effort (not ability) fills the wardrobe.
  • Topic badge tiers — each Bronze / Silver / Gold gives a named item themed on that topic (17 topics × 3 = 51 items). The good stuff comes from real progress.
  • Legendaries — one per science, held live by whoever has the most correct answers in it. Lose the lead, lose the item.
  • Set bonus — wear 3 items from the same science → a title (e.g. “Certified Lab Gremlin”).
